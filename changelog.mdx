- Introduced webhook support for custom event notifications.

- Fixed intermittent failures in Codespaces integration.

<Update label="2024-09-10" description="v1.1.0" tags={["breaking", "feature"]}>

## Breaking Changes

- Updated authentication endpoint from `/auth/login` to `/v2/auth/login`.
- Removed deprecated `legacyToken` parameter.

## New Features

- Advanced security scanning for code vulnerabilities.
- Dashboard analytics for developer workflows.

## Migration Steps

Follow these steps to update your integration:

<Steps>
<Step title="Update Dependencies" icon="download">

Run the upgrade command:

````bash
npm install riven@latest
````

</Step>
<Step title="Replace Deprecated Endpoint" icon="settings">

Update your API calls:

````javascript
// Old
fetch('https://api.example.com/auth/login', { ... });

// New
fetch('https://api.example.com/v2/auth/login', { ... });
````

</Step>
<Step title="Test Authentication" icon="check-circle">

Verify token refresh works in your app.

</Step>
</Steps>

</Update>
