## Overview

Start building on Riven's Emelambda platform in minutes.

## Steps

<Steps>
  <Step title="Initialize project">
    ````bash
    riven init my-app --template=emelambda
    cd my-app
    ````
  </Step>
  <Step title="Deploy">
    ````bash
    riven deploy
    # Visit the dashboard to monitor status
    ````
  </Step>
</Steps>

<Callout kind="tip">
Check docs.riven.ai for advanced configuration.
</Callout>
